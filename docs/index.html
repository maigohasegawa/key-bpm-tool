キー/BPM 照合ツール

Spotify のプレイリストURLを貼るだけで、収録曲の BPM とキーを楽曲データベースから調べ、マッシュアップに使える組み合わせを相性の良い順に並べます。音源は使わず、曲名とアーティスト名から調べます。

ダウンロード（ZIP） GitHub で見る Mac / Windows ・ Python 3 が必要

こんな結果が出ます

曲 A124.9 BPM · Am（8A）
×
曲 B63 BPM · C（8B）
B×2で +0.9% 平行調・移調不要

表示例。曲Bを倍テンポとして扱えば伸縮は1%未満、キーは平行調なので移調せずに重ねられる、という読み方です。

使い方

  1. ダウンロードして解凍上のボタンから ZIP を取得します。
  2. 起動ファイルをダブルクリックMac は「起動（Mac）.command」、Windows は「起動（Windows）.bat」。ブラウザに画面が開きます。
  3. URLを貼って「解析する」Spotify の「共有 → リンクをコピー」で取れるプレイリストURLを使います。

できること

  • マッシュアップ候補全曲の総当たりで、テンポの伸縮率と移調量が小さい組み合わせを表示。倍・半分テンポにも対応します。
  • 曲で絞り込み1曲を選ぶと、その曲に合う相手だけを表示。アカペラに合うオケ探しに。
  • 複数データベースで照合BPMの倍/半分や平行調の取り違えなど、値がずれている曲に「要確認」の印を付けます。
  • 基準曲との比較BPM差、キー差（半音）、Camelot、相性を一覧で。CSVでも保存できます。

データの取得元

データベース役割設定
GetSongBPMBPM・キーの標準の取得元無料の APIキーを画面の「設定」から登録
ReccoBeatsGetSongBPM に見つからない曲を補う／照合不要
SoundStat3つ目の照合先（任意）APIキーが必要

BPM・キーのデータは GetSongBPM.com と ReccoBeats の提供によるものです。
